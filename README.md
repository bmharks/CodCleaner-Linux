# CodCleaner-Linux
This is a simple script that cleans out downloaded maps/files from the multiplayer of CoD1 and CoDUO. This script moves these files out of the main/uo folders into a new folder named archived_maps. Do be aware, CodCleaner will remove any intentionally downloaded singleplayer maps/mods. This script can be automated by putting it in the game folder and adding the launch options "./codcleaner.sh && PROTON_OLD_GL_STRING=1 %command%" to your game properties in Steam (you may replace the Proton string with other preferred launch options). Automating this prevents file mismatches when joining games, but does require maps to be redownloaded each time you join the game. This does not effect mods as they download to a different directory. This should work with all versions of the game, but was only tested with CoD1.5 and CoDUO1.5
